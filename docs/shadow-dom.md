## 宿主边界

已核对全插件的 DOM 挂载入口，未发现其他独立业务窗口留在宿主 DOM。世界书全文预览、API 编辑、菜单、衣橱及确认框均挂在已有主面板或弹窗根内。

构画自绘内容已完成隔离。工具栏和魔杖菜单保留宿主定位节点，原生 Quick Reply 继续由酒馆绘制。复制、下载及安全区测量使用的临时节点不承载可见界面。

## 楼层收藏图标

外层原生按钮保留类名、顺序、点击事件与收藏状态；`sp-anchor-icon` 的开放 Shadow Root 只承载图标，基础样式内联，不等待外部样式加载。颜色继承按钮，尺寸沿用普通入口的固定值和宿主工具栏的 `1em`。重复扫描复用原节点与根，酒馆恢复出的无根图标会就地隔离。

模拟 DOM 回归覆盖双入口、收藏与取消、忙碌状态、重复扫描、第三方排序、Tauri 插入位置及移除。最后这一步未新增浏览器实机验证。

## 魔杖菜单入口

外层 `#sp_open_wand` 保留酒馆菜单的定位、间距与点击行为。图标和名称在开放 Shadow Root 内显示，使用内联基础样式，挂载时即可显示。原 Light DOM 内容不参与绘制，仅保留给酒馆读取名称与识别键盘入口。

模拟 DOM 回归覆盖直接／延迟挂载、重复初始化不新增监听及点击仅打开一次；主题下的实际显示随日常使用继续验证。

## 窗口定位

`ui/panel-window.js` 与 `index.js` 的视口同步共同管理位置。桌面使用浏览器可视范围，支持拖动、缩放及位置尺寸恢复。手机跟随可视视口变化，页面实际滚动时补偿根元素偏移。

手机Safari与iPhone Firefox文本编辑期间保留主窗几何，主动打开、旋转与独立弹窗继续同步。原Safari反馈者已确认4.2.2解决问题；另一位用户更正为Firefox，本地已补FxiOS匹配，实机效果待确认。仓库回归与Chromium尺寸模拟分别记录；iPad Safari实机键盘行为仍待验证。

## 楼内挂载与事件

`business/inline/feature.js` 管理每个楼内根。外壳 `.sp-inline-box.sp-inline-host` 用于宿主识别与收藏排除，原折叠框和模块内容位于开放 Shadow Root 中，加载同一版本的 `style.css`。

`bindRoots(key, binder)` 将点、线和标注池事件绑定到根内的实际容器，`getRoots()` 提供当前根集合供主题与图标同步。历史楼通过宿主回溯消息身份，重绘和卸载保留总框、模块与事项的展开状态。名字打码按新宿主局部发现，收藏正文沿外壳排除楼内内容。

内容更新复用已加载样式的根与事件容器。新根在样式就绪后显示内容，宿主层显式关闭浏览器触摸高亮。

当前渲染深度内的框首次入屏时挂载，离屏后保留节点与高度，退出深度范围时释放。

仓库测试及 Chromium 桌面亮色、手机窄屏暗色模拟通过，覆盖历史只读、分层展开、重挂状态、点详情、主题隔离、名字打码与收藏。Safari 实机交互待验证。
